# Zoiko Sports — frontend

React + TypeScript (Vite) sign-in app: the four workspace sign-ins, registration,
verification and password reset, light/dark theme with the expandable theme toggle.

**Full documentation** — architecture, setup, environment variables, theme,
layout system, testing and troubleshooting — is in the
[repository README](../README.md).

## Quick reference

```sh
npm install            # once
npm run dev            # http://localhost:5173/login (API on 127.0.0.1:8000)
npm run build          # type-check + production build
npm run lint
npm run test:e2e       # Playwright suite (own backend on :8010, preview on :5183)
```
